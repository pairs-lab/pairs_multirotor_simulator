# pairs_multirotor_simulator

PAIRS multirotor dynamics simulator — lightweight ODE-based multi-UAV physics with a hw_api plugin.

This is the **ros1** branch (ROS 1 Noetic, catkin). For ROS 2 Jazzy (ament_cmake), see the `ros2` branch.
